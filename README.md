# Autorouter benchmark dashboard

This is a static Vercel dashboard generated by
[`scripts/benchmark/benchmark-history.ts`](https://github.com/tscircuit/tscircuit-autorouter/blob/main/scripts/benchmark/benchmark-history.ts).

`index.html`, `index.css`, and `index.js` are application assets. The compact
`data/index.json` manifest contains trend data; full reports are served as
separate `data/runs/<workflow-run>-<attempt>.json` files and fetched only when
a run is inspected.

Run locally with:

```sh
vercel dev --local
```
